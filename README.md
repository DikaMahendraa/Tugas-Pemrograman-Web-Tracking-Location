## ✨ Fitur Utama

- **Create:** Menambahkan data lokasi baru.
- **Read:** Menampilkan daftar lokasi.
- **Update:** Memperbarui informasi lokasi.
- **Delete:** Menghapus data lokasi.


## 🖥️ Panduan Penggunaan Aplikasi

GeoTrack memiliki beberapa fitur utama yang dapat digunakan untuk mengelola data lokasi.

### 1. Dashboard

Halaman utama aplikasi yang menampilkan seluruh data lokasi dalam bentuk tabel. Pada halaman ini, pengguna dapat melihat informasi lokasi yang telah disimpan, jumlah data lokasi, serta mengakses berbagai fitur pengelolaan data.

### 2. Tambah Lokasi

Digunakan untuk menyimpan data lokasi baru. Pengguna dapat mengisi beberapa informasi berikut:

- **Nama Lokasi:** Nama tempat yang ingin disimpan.
- **Kategori:** Jenis atau kelompok lokasi, seperti Pendidikan, Wisata, Olahraga, dan lainnya.
- **Catatan:** Informasi tambahan mengenai lokasi.
- **Latitude:** Koordinat garis lintang.
- **Longitude:** Koordinat garis bujur.

Aplikasi juga menyediakan fitur geolocation browser untuk membantu mengambil koordinat lokasi pengguna setelah mendapatkan izin akses lokasi.

### 3. Lihat Data Lokasi

Data lokasi yang berhasil disimpan akan ditampilkan pada tabel dashboard. Informasi yang ditampilkan meliputi nama lokasi, kategori, latitude, longitude, tanggal penyimpanan, dan tindakan yang dapat dilakukan.

### 4. Edit Lokasi

Digunakan untuk memperbarui informasi lokasi yang sudah tersimpan. Pengguna dapat mengubah nama lokasi, kategori, catatan, maupun koordinat, kemudian menyimpan perubahan tersebut.

### 5. Hapus Lokasi

Digunakan untuk menghapus data lokasi yang sudah tidak diperlukan dari database.

### 6. Pencarian Lokasi

Memungkinkan pengguna mencari data berdasarkan nama lokasi sehingga data tertentu lebih mudah ditemukan.

### 7. Filter Kategori

Digunakan untuk menampilkan lokasi berdasarkan kategori tertentu, sehingga pengguna dapat mengelompokkan data sesuai jenis lokasinya.

### 8. Pagination

Digunakan untuk membagi daftar lokasi ke beberapa halaman. Fitur ini membantu menjaga tampilan tabel tetap teratur ketika jumlah data semakin banyak.

## 🔄 Alur Penggunaan Aplikasi

1. Pengguna membuka halaman dashboard GeoTrack.
2. Pengguna dapat menambahkan lokasi baru melalui tombol Tambah Lokasi.
3. Pengguna mengisi informasi lokasi beserta koordinatnya.
4. Data disimpan ke database MySQL.
5. Data yang tersimpan ditampilkan pada dashboard.
6. Pengguna dapat mencari, memfilter, mengedit, atau menghapus data sesuai kebutuhan.
